# UK9004171_bysea_3035

Distance by sea (km) from the Forth Islands SPA (UK9004171) colony to
each sea cell, avoiding land, on the 1 km EPSG:3035 grid. Used as
`fltdist_base` in the GPS kittiwake example.

## Usage

``` r
UK9004171_bysea_3035
```

## Format

A list with two elements, used to rebuild the raster in memory:

- matrix:

  Matrix of cell values.

- metadata:

  List of metadata: extent, resolution and CRS.
