# UK9002491_bysea_3035

Distance by sea (km) from the Buchan Ness to Collieston Coast SPA
(UK9002491) colony to each sea cell, avoiding land, on the 1 km
EPSG:3035 grid. Used as `fltdist_base` in the distance-decay kittiwake
example.

## Usage

``` r
UK9002491_bysea_3035
```

## Format

A list with two elements, used to rebuild the raster in memory:

- matrix:

  Matrix of cell values.

- metadata:

  List of metadata: extent, resolution and CRS.
