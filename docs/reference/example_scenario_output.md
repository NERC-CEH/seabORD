# example_scenario_output

Precomputed seabORD output from the Forth Islands kittiwake scenario run
with Inch Cape and Neart na Gaoithe, used in the examples.

## Usage

``` r
example_scenario_output
```

## Format

A named list, as returned by
[`seabord()`](https://nerc-ceh.github.io/seabORD/reference/seabord.md):

- switches:

  List: the run options used.

- Parameters:

  List: the biological and simulation parameters used.

- ordPar:

  List: the ORD settings used.

- modPar:

  List: the model environment and output settings used.

- thisRun:

  List: run details stored for reproducibility.

- output_f0:

  List of tibbles: flight metrics.

- output_c0:

  List of tibbles: chick metrics.

- output_a0:

  List of tibbles: adult metrics.

- output_y0:

  List of tibbles: over-winter survival metrics.

- BirdFlightMap:

  Raster: number of simulated visits to each foraging location.

- output_i0 to output_i5:

  Lists of tibbles: impact metrics (see Interpreting the outputs).

## Source

Generated by
