# CEF colony size table

Breeding colony sizes for each species at each SPA, taken from the
Cumulative Effects Framework (CEF).

## Usage

``` r
CEF_colsize_table
```

## Format

A data frame with 5 columns:

- X:

  Numeric: Row index.

- species:

  Character: The species code.

- site_codes:

  Character: The unique code identifying each site.

- site_names:

  Character: The name of the site.

- spacolsize:

  Numeric: Colony size at the SPA, in breeding pairs.

## Source

Cumulative Effects Framework (CEF).
